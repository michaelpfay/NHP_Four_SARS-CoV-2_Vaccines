Files ending in .Rmd are R markdown files that run on free R software (see e.g., https://rmarkdown.rstudio.com/ ).

Files that start with "COP" create analyses that match with the specified section of the Statistical Analysis Plan.

"paper figures.Rmd" create the figures in the paper.


All data are in one file in the data directory. Results were created using R version 4 (4.0.0-4.5.2).

R should be run from the same directory as the files and the data file should be in the /data subdirectory of that directory so that the data file can be found.
